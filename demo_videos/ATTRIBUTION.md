# Sample videos

`python backend/main.py --demo` (and `scripts/fetch_samples.py`) download these clips on first
use and check each one's SHA-256. The videos are not stored in git.

| File | Source | Scenario |
|---|---|---|
| `corridor_sample.mp4` | [people-detection.mp4](https://github.com/intel-iot-devkit/sample-videos/blob/master/people-detection.mp4) | `--demo corridor` |
| `walking_sample.mp4` | [one-by-one-person-detection.mp4](https://github.com/intel-iot-devkit/sample-videos/blob/master/one-by-one-person-detection.mp4) | `--demo hallway` |
